# 0.02 — Reading error messages

You'll spend more time reading errors than writing new code. Getting fast at it is the cheapest speed-up in programming.

## Anatomy of a traceback

```text
Traceback (most recent call last):
  File "report.py", line 12, in <module>
    total = add_tax(price)
  File "report.py", line 4, in add_tax
    return amount * (1 + RATE)
                          ^^^^
NameError: name 'RATE' is not defined
```

Read it **bottom-up**:

1. **Last line — what went wrong.** `NameError: name 'RATE' is not defined`. The type (`NameError`) tells you the category; the message tells you the specifics.
2. **The frame just above — where it went wrong.** `line 4, in add_tax`. The `^^^^` marks point at the exact expression.
3. **Frames further up — how you got there.** Line 12 called `add_tax`. Useful when the bug is in what was *passed in*, not in the function itself.

In notebooks the layout is the same, with cells shown as `Cell In[5], line 3`.

## The errors you'll meet most

| Error | Usually means | Example |
|---|---|---|
| `SyntaxError` | Python can't even parse it — missing `:`, bracket or quote | `if x > 3 print(x)` |
| `IndentationError` | Inconsistent indentation | mixing tabs and spaces |
| `NameError` | Using a name that doesn't exist (typo, or cell not run) | `pritn("hi")` |
| `TypeError` | Right name, wrong kind of value | `"3" + 4` |
| `ValueError` | Right type, unacceptable value | `int("3.7")` |
| `IndexError` | List position doesn't exist | `[1, 2][5]` |
| `KeyError` | Dict key doesn't exist | `{"a": 1}["b"]` |
| `AttributeError` | That object has no such method/attribute | `[1, 2].push(3)`, or calling a method on `None` |
| `ZeroDivisionError` | Division by zero | `10 / 0` |
| `ModuleNotFoundError` | Package not installed in *this* environment, or wrong kernel | `import pandsa` |

### The sneaky one: `'NoneType' object has no attribute ...`

```python
names = ["b", "a"]
sorted_names = names.sort()   # .sort() sorts in place and returns None
sorted_names.append("c")      # AttributeError: 'NoneType' object has no attribute 'append'
```

The error appears on line 3, but the bug is on line 2. When you see `NoneType`, ask: *"which earlier line gave me `None` when I expected a value?"* — usually a function that `print`s instead of `return`s, or an in-place method.

## A routine for any error

1. Read the last line out loud.
2. Go to the line the traceback points at.
3. Print (or inspect in the debugger) every variable on that line. One of them isn't what you think.
4. If the variable is wrong, go *up* to where it was created.
5. Still stuck? Paste the error into a search engine *without* your variable names.
