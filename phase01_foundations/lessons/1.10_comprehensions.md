# 1.10 — Comprehensions

A comprehension builds a list, dict or set in one expression. Agent-written code uses them constantly, so you must read them instantly — and write them for simple cases.

## List comprehension

```python
# loop version
squares = []
for x in range(6):
    squares.append(x ** 2)

# comprehension
squares = [x ** 2 for x in range(6)]        # [0, 1, 4, 9, 16, 25]
```

Read it as: **[ what to put in | for each item | (optional) if it passes ]**

```python
evens_squared = [x ** 2 for x in range(10) if x % 2 == 0]
names = [c["name"].title() for c in customers if c["active"]]
```

## Condition *before* `for` = choose a value (if/else)

```python
labels = ["big" if a > 10_000 else "small" for a in amounts]
```

- `[x for x in xs if cond]` → **filters** (fewer items).
- `[a if cond else b for x in xs]` → **transforms** every item (same number of items).

## Dict and set comprehensions

```python
lengths = {name: len(name) for name in ["ana", "bo"]}          # {'ana': 3, 'bo': 2}
passed = {k: v for k, v in scores.items() if v >= 50}          # filter a dict
by_id = {c["id"]: c for c in customers}                        # index records by id
domains = {e.split("@")[1] for e in emails}                    # unique domains
```

## Nested comprehensions

```python
matrix = [[1, 2, 3], [4, 5, 6]]
flat = [x for row in matrix for x in row]     # [1, 2, 3, 4, 5, 6]
```

The `for` clauses are in the **same order** as nested loops would be:

```python
flat = []
for row in matrix:
    for x in row:
        flat.append(x)
```

Transpose — a comprehension inside a comprehension:

```python
[[row[i] for row in matrix] for i in range(len(matrix[0]))]   # [[1, 4], [2, 5], [3, 6]]
```

## Generator expressions — no brackets

Inside a function call, you can drop the brackets:

```python
total = sum(tx["amount"] for tx in txs if tx["category"] == "Dining")
any(a > 100_000 for a in amounts)       # True if at least one
all(a > 0 for a in amounts)             # True if every one
```

These don't build a list in memory — they produce values one at a time (more in Phase 4).

## When NOT to use one

If it needs more than one `if`, nested conditions, or doesn't fit on one or two readable lines, use a loop. Comprehensions are for simple transform-and-filter. Also never use a comprehension just for side effects (`[print(x) for x in xs]`) — that's what `for` is for.

## Reading strategy for dense agent code

When you meet a hard comprehension, rewrite it as loops on paper: start from the first `for`, nest the next `for`/`if` inside it, and put the expression at the front into `.append(...)` at the innermost level.
