# 1.07 — Dictionaries

A dict maps **keys** to **values**. It's the most important data structure for you: JSON, API responses, LLM tool calls, config files and database rows all arrive as dicts.

## Basics

```python
tx = {"date": "2026-09-01", "merchant": "Keells", "amount": 4500.0}
tx["merchant"]            # 'Keells'
tx["amount"] = 4750.0     # update
tx["category"] = "Groceries"   # add a new key
del tx["date"]            # remove
"amount" in tx            # True - `in` checks KEYS, not values
len(tx)                   # number of keys
```

Keys must be immutable (strings, numbers, tuples). Values can be anything, including lists and other dicts.

## Safe access with `.get`

```python
tx["tip"]              # KeyError
tx.get("tip")          # None
tx.get("tip", 0)       # 0 - your default
```

## Looping

```python
for key in tx:                    # keys
    ...
for value in tx.values():
    ...
for key, value in tx.items():     # both - the one you'll use most
    print(f"{key}: {value}")
```

Dicts remember insertion order.

## Pattern 1 — counting

```python
def word_counts(text):
    counts = {}
    for word in text.lower().split():
        counts[word] = counts.get(word, 0) + 1
    return counts
```

Read the key line as: *"the count for this word is whatever it was (or 0) plus one"*.

## Pattern 2 — grouping

```python
def group_by_category(transactions):
    groups = {}
    for tx in transactions:
        cat = tx["category"]
        if cat not in groups:
            groups[cat] = []
        groups[cat].append(tx)
    return groups
```

## Pattern 3 — summing by key

```python
totals = {}
for tx in transactions:
    totals[tx["category"]] = totals.get(tx["category"], 0) + tx["amount"]
```

## Pattern 4 — lookup table instead of if/elif

```python
RATES = {"USD": 300.5, "EUR": 325.1, "GBP": 382.0}
def to_lkr(amount, currency):
    return amount * RATES[currency]
```

## Finding the key with the biggest value

```python
best_key = None
for key, value in totals.items():
    if best_key is None or value > totals[best_key]:
        best_key = key

# or, once you know it:
best_key = max(totals, key=totals.get)
```

## Nested data — the shape of every API response

```python
response = {
    "id": "msg_01",
    "content": [{"type": "text", "text": "Hello"}],
    "usage": {"input_tokens": 12, "output_tokens": 5},
}
response["content"][0]["text"]         # 'Hello'
response["usage"]["output_tokens"]     # 5
```

Read these from the outside in: dict → key `"content"` → list → position 0 → dict → key `"text"`. When a level might be missing, `.get` at each step, or check before you index.

## Sorting a dict by value

```python
sorted(totals.items(), key=lambda kv: kv[1], reverse=True)   # list of (key, value) pairs
```

(`lambda` gets a proper explanation in 1.09.)

## Other useful methods

```python
d.keys(), d.values(), d.items()
d.update({"a": 1})        # merge another dict in
d.pop("a", None)          # remove and return, with default
d.setdefault("k", [])     # get, or insert default and return it
merged = {**d1, **d2}     # new dict; d2 wins on shared keys
merged = d1 | d2          # same, Python 3.9+
```
