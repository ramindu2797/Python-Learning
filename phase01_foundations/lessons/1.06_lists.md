# 1.06 — Lists

A list is an ordered, changeable collection. It's Python's workhorse container.

## Creating, indexing, slicing

```python
spend = [52000, 48000, 61000, 45000]
spend[0]        # 52000
spend[-1]       # 45000
spend[1:3]      # [48000, 61000]   same slicing rules as strings
len(spend)      # 4
[]              # empty list
list("abc")     # ['a', 'b', 'c']
list(range(3))  # [0, 1, 2]
```

## Changing a list (these modify it *in place*)

```python
xs = [3, 1, 2]
xs.append(5)        # [3, 1, 2, 5]        add one item at the end
xs.extend([7, 8])   # [3, 1, 2, 5, 7, 8]  add several
xs.insert(0, 99)    # [99, 3, 1, 2, 5, 7, 8]
xs.pop()            # returns 8; removes the last item
xs.pop(0)           # returns 99; removes position 0
xs.remove(2)        # removes the first 2 (ValueError if absent)
xs[0] = 10          # replace by position
del xs[1]           # delete by position
```

`append` vs `extend`: `xs.append([7, 8])` adds **one** item (a list inside the list); `xs.extend([7, 8])` adds two.

## Built-ins that work on lists

```python
sum(spend), min(spend), max(spend), len(spend)
sorted(spend)                   # new sorted list; original unchanged
sorted(spend, reverse=True)
spend.sort()                    # sorts in place, returns None
list(reversed(spend))
spend.index(61000)              # position of first match
spend.count(48000)
48000 in spend                  # membership (scans the list)
```

**`sorted(x)` vs `x.sort()`** — `sorted` returns a new list; `.sort()` changes `x` and returns `None`. `x = x.sort()` destroys your list (it's now `None`).

## Aliasing: two names, one list

```python
a = [1, 2, 3]
b = a            # NOT a copy - b and a are the same list
b.append(4)
print(a)         # [1, 2, 3, 4]

c = a.copy()     # a real (shallow) copy; also a[:] or list(a)
c.append(5)
print(a)         # [1, 2, 3, 4] - unaffected
```

This matters for functions: if a function modifies a list it was given, the caller sees the change. Unless the problem says "in place", **don't modify your inputs** — build a new list.

## Lists of lists (tables, matrices)

```python
matrix = [[1, 2, 3],
          [4, 5, 6]]
matrix[1][2]        # 6   row 1, column 2
len(matrix)         # 2 rows
len(matrix[0])      # 3 columns

for row in matrix:
    for value in row:
        ...
```

Trap: `[[0] * 3] * 2` creates two references to the *same* inner list. Build grids with a loop or comprehension instead: `[[0] * 3 for _ in range(2)]`.

## Common list patterns

```python
# filter: build a new list of the items that pass a test
big = []
for x in spend:
    if x > 50000:
        big.append(x)

# transform: build a new list from each item
with_tax = []
for x in spend:
    with_tax.append(round(x * 1.18, 2))

# pairwise: look at neighbours
for i in range(1, len(spend)):
    change = spend[i] - spend[i - 1]
```

## Unpacking

```python
first, second, *rest = [10, 20, 30, 40]   # first=10, second=20, rest=[30, 40]
```
