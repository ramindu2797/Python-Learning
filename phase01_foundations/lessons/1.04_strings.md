# 1.04 — Strings

A string is an ordered sequence of characters. Most real data arrives as strings — CSV cells, API responses, LLM outputs — so fluency here pays off everywhere.

## Indexing and slicing

```python
s = "PYTHON"
#    012345      positions from the left
#   -654321      positions from the right (use with a minus sign)

s[0]      # 'P'
s[-1]     # 'N'   last character
s[1:4]    # 'YTH' from 1 up to (not including) 4
s[:2]     # 'PY'  from the start
s[3:]     # 'HON' to the end
s[::2]    # 'PTO' every 2nd character
s[::-1]   # 'NOHTYP' reversed
len(s)    # 6
```

Slices never raise `IndexError` — `s[2:100]` just stops at the end. Plain indexes do: `s[10]` fails.

## Strings are immutable

```python
s = "hello"
s[0] = "H"            # TypeError
s = "H" + s[1:]       # build a new string instead
```

Every string method returns a **new** string; the original is untouched. So `name.strip()` on its own line does nothing useful — you must write `name = name.strip()`.

## The methods you'll use constantly

```python
raw = "  Jane.Doe@Example.COM "
raw.strip()                 # 'Jane.Doe@Example.COM'   remove surrounding whitespace
raw.lower() / raw.upper()
"a,b,,c".split(",")         # ['a', 'b', '', 'c']      split on a separator
"one  two\tthree".split()   # ['one', 'two', 'three']  no argument = any whitespace
"-".join(["2026", "09", "26"])   # '2026-09-26'        the reverse of split
"LKR 1,500".replace(",", "")     # 'LKR 1500'
"report.csv".endswith(".csv")    # True   (also startswith)
"banana".find("an")              # 1      (-1 if not found)
"banana".count("a")              # 3
"2026".isdigit()                 # True
"hello world".title()            # 'Hello World'
"x".center(5, "*")               # '**x**'
```

Chaining is normal and readable:

```python
email = raw.strip().lower()
user, domain = email.split("@")      # unpack the two parts
```

## Looping over a string

```python
for ch in "abc":
    print(ch)
```

## Building strings piece by piece

```python
parts = []
for word in ["data", "is", "rarely", "clean"]:
    parts.append(word.upper())
result = " ".join(parts)             # fast and clean
```

Adding with `+` in a loop works but is slower for big strings; `join` a list is the idiom.

## Character tests and codes

```python
"a".isalpha(), "7".isdigit(), " ".isspace(), "A".isupper()
ord("A")   # 65   character -> number
chr(66)    # 'B'  number -> character
```

## Multi-line strings

```python
msg = """Line one
Line two"""
```

## Common mistakes

- Forgetting to reassign: `s.strip()` alone changes nothing.
- `split()` vs `split(" ")`: with no argument, repeated spaces are treated as one; with `" "`, you get empty strings between them.
- Comparing strings with different case or whitespace. Normalise first: `a.strip().lower() == b.strip().lower()`.
