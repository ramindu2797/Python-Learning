# 1.03 — Conditionals

Conditionals let code choose what to do.

## Comparisons produce booleans

```python
5 > 3        # True
5 == 5.0     # True   (== compares values)
"a" != "b"   # True
3 <= 3       # True
0 < x < 10   # chained: same as (0 < x) and (x < 10)
"LKR" in "Amount in LKR"   # True - substring test
3 in [1, 2, 3]             # True - membership test
```

`=` assigns; `==` compares. Mixing them up is a classic bug (Python catches most cases as a `SyntaxError`).

## `and`, `or`, `not`

```python
age, income = 30, 250_000
age >= 21 and income > 100_000      # True: both must be true
age < 18 or income > 1_000_000      # False: at least one must be true
not (age < 18)                      # True
```

Python stops evaluating as soon as the answer is known ("short-circuit"): in `x != 0 and 10 / x > 2`, the division never runs when `x` is 0.

## `if` / `elif` / `else`

```python
def credit_band(score):
    if score >= 750:
        return "Excellent"
    elif score >= 650:
        return "Good"
    elif score >= 550:
        return "Fair"
    else:
        return "Poor"
```

Python checks conditions **top to bottom and takes the first true one**. That's why the order above works: a score of 800 is also `>= 650`, but it never gets that far. Put the most specific / highest bands first.

Because each branch `return`s, the `else` is optional — this is a common, clean style called **early return**:

```python
def shipping(weight_kg):
    if weight_kg <= 0:
        return 0
    if weight_kg <= 1:
        return 500
    return 500 + 200 * (weight_kg - 1)
```

## Truthiness

In an `if`, Python treats these as **False**: `0`, `0.0`, `""`, `[]`, `{}`, `set()`, `None`. Everything else is **True**.

```python
items = []
if not items:
    print("nothing to process")    # idiomatic way to test "empty"
```

Careful: `if value:` is False for `0` too. If 0 is a valid value, test `if value is None:` instead.

## `is None`

Use `is` (identity) only for `None`: `if result is None:`. For everything else use `==`.

## Conditional expression (one-line if)

```python
label = "high" if amount > 10_000 else "normal"
```

Good for simple choices. If it doesn't fit on one readable line, use a normal `if`.

## Nested conditions → flatten them

```python
# harder to read
if age >= 18:
    if income > 100_000:
        return "eligible"
return "not eligible"

# easier
if age >= 18 and income > 100_000:
    return "eligible"
return "not eligible"
```

## Useful helpers

`math.ceil(x)` rounds up — handy for "per started kilogram / per started hour" rules. `min(a, b)` / `max(a, b)` often replace an `if` entirely: `taxable = max(income - allowance, 0)`.
