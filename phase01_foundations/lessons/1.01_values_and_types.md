# 1.01 — Values, variables and types

Everything in Python is a **value** of some **type**. A **variable** is a name that points at a value.

## The core types

| Type | Examples | Notes |
|---|---|---|
| `int` | `42`, `-7`, `1_000_000` | Whole numbers, any size. Underscores are just for readability. |
| `float` | `3.14`, `1e-3`, `2.0` | Decimals. Stored in binary, so tiny rounding errors happen. |
| `str` | `"hello"`, `'LKR'`, `""` | Text. Single or double quotes — same thing. |
| `bool` | `True`, `False` | Capitalised. |
| `NoneType` | `None` | "No value". What a function returns if it has no `return`. |

```python
amount = 1250.5
currency = "LKR"
is_paid = False
note = None

print(type(amount), type(currency), type(is_paid), type(note))
# <class 'float'> <class 'str'> <class 'bool'> <class 'NoneType'>
```

## Variables are labels, not boxes

```python
x = 10
y = x       # y points at the same value 10
x = 20      # x now points at 20; y still points at 10
print(y)    # 10
```

Names: lowercase with underscores (`monthly_total`), start with a letter, and never shadow built-ins like `list`, `sum`, `max`, `type`.

## Arithmetic

```python
7 + 2     # 9
7 - 2     # 5
7 * 2     # 14
7 / 2     # 3.5   (always a float)
7 // 2    # 3     floor division: rounds DOWN to a whole number
7 % 2     # 1     remainder ("modulo")
7 ** 2    # 49    power
-7 // 2   # -4    (down, not towards zero!)
```

`//` and `%` together split a quantity into parts:

```python
seconds = 7384
hours = seconds // 3600            # 2
minutes = (seconds % 3600) // 60   # 3
secs = seconds % 60                # 4
```

Shortcuts: `total += 5` means `total = total + 5` (also `-=`, `*=`, `/=`).

## Converting between types

```python
int("42")       # 42
float("3.5")    # 3.5
str(99)         # "99"
int(3.9)        # 3   - truncates toward zero, does NOT round
round(3.9)      # 4
round(2.5)      # 2   - "banker's rounding": halves go to the even number
round(1234.5678, 2)  # 1234.57
int("3.9")      # ValueError - int() on a string needs a whole number
bool(0), bool(""), bool("0")   # False, False, True  (non-empty string is True)
```

## f-strings — how you'll format almost everything

Put `f` before the quote and expressions in `{}`:

```python
name, total = "Ramindu", 3751.5
print(f"{name} spent {total} LKR")          # Ramindu spent 3751.5 LKR
print(f"{total:,.2f}")                        # 3,751.50     thousands separator, 2 decimals
print(f"{0.1234:.1%}")                        # 12.3%        percentage
print(f"[{name:>10}]")                        # [   Ramindu] right-align in 10 characters
print(f"[{name:<10}]")                        # [Ramindu   ] left-align
print(f"{7:03d}")                             # 007          zero-pad
print(f"{total=}")                            # total=3751.5  handy for debugging
```

The pattern inside `{}` is `{value:format}` — `,` thousands, `.2f` two decimals, `%` percent, `>10` right-align width 10.

## Floats are approximate

```python
0.1 + 0.2 == 0.3            # False!
0.1 + 0.2                   # 0.30000000000000004
import math
math.isclose(0.1 + 0.2, 0.3)   # True - compare floats this way
```

For money in real systems, use integer cents or `decimal.Decimal`. For this course, floats plus rounding are fine.

## The `math` module

```python
import math
math.sqrt(16)      # 4.0
math.ceil(2.1)     # 3   round up
math.floor(2.9)    # 2   round down
math.pi, math.e
math.log(100, 10)  # 2.0
```

## Reading agent code

You'll see type hints like `amount: float = 0.0` and `def f(x: int) -> str:`. They're documentation for humans and tools; Python doesn't enforce them at runtime. You'll learn them properly in Phase 4.
