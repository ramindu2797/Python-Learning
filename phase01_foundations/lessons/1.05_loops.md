# 1.05 — Loops

Loops repeat work. Almost every problem you'll solve has a loop at its heart, so this module gets 4 sessions.

## `for` — do something for each item

```python
for amount in [1200, 450, 3000]:
    print(amount * 1.18)

for ch in "LKR":
    print(ch)
```

`for` works on anything **iterable**: lists, strings, dicts, files, ranges…

## `range` — counting

```python
range(5)          # 0, 1, 2, 3, 4
range(2, 6)       # 2, 3, 4, 5        stop is excluded
range(0, 10, 3)   # 0, 3, 6, 9        step
range(5, 0, -1)   # 5, 4, 3, 2, 1     counting down
```

## The accumulator pattern

Most loops follow this shape — *initialise, update in the loop, use after*:

```python
def total_spend(amounts):
    total = 0                  # 1. initialise before the loop
    for a in amounts:
        total += a             # 2. update inside
    return total               # 3. use after (NOT inside the loop)
```

Accumulators can be numbers, strings, lists, dicts, or "best so far":

```python
def largest(values):
    best = values[0]
    for v in values[1:]:
        if v > best:
            best = v
    return best
```

A very common bug is putting `return` inside the loop — the function then stops after the first item.

## `while` — repeat until a condition changes

Use `while` when you don't know in advance how many iterations you need:

```python
def years_to_double(rate):
    balance, years = 1.0, 0
    while balance < 2.0:
        balance *= 1 + rate
        years += 1
    return years
```

Make sure something inside the loop moves you towards the exit, or it runs forever (stop it with the ⏹ button / *Interrupt kernel*).

## `break` and `continue`

```python
for tx in transactions:
    if tx < 0:
        continue      # skip this one, go to the next item
    if tx > 1_000_000:
        break         # stop the loop completely
    process(tx)
```

## `enumerate` — index and value together

```python
for i, name in enumerate(["a", "b", "c"]):
    print(i, name)        # 0 a / 1 b / 2 c

for i, name in enumerate(names, start=1):   # count from 1
    ...
```

Prefer this over `for i in range(len(names)):` unless you really need to look at neighbours (`names[i - 1]`).

## `zip` — walk two sequences in step

```python
months = ["Jan", "Feb", "Mar"]
spend = [52000, 48000, 61000]
for m, s in zip(months, spend):
    print(f"{m}: {s:,}")
```

`zip` stops at the shorter sequence.

## Nested loops

```python
for row in range(1, 4):
    for col in range(1, 4):
        print(row * col, end=" ")
    print()          # new line after each row
```

The inner loop runs completely for *each* step of the outer loop: 3 × 3 = 9 prints.

## Digit tricks with `%` and `//`

```python
n = 4827
n % 10     # 7   last digit
n // 10    # 482 drop the last digit
```

A `while n > 0:` loop with these two peels a number apart digit by digit.

## Trace tables: your main debugging tool now

Before running any loop, write a table with one row per iteration and one column per variable, and fill it by hand for a small input. Then run the code (or step through with the debugger). If the results differ, you've found your misunderstanding — the fastest way to learn.
