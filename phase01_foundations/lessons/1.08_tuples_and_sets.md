# 1.08 — Tuples and sets

## Tuples — fixed sequences

A tuple is like a list you can't change. Use it for a small, fixed group of values that belong together.

```python
point = (3, 4)
point[0]          # 3
point[0] = 5      # TypeError - immutable
single = (7,)     # a 1-tuple needs the trailing comma
```

### Returning several values

```python
def min_max(values):
    return min(values), max(values)     # the parentheses are optional; this returns a tuple

lo, hi = min_max([4, 9, 1])             # unpacking: lo=1, hi=9
```

### Swapping and unpacking

```python
a, b = b, a                 # swap without a temp variable
name, (lat, lon) = ("Colombo", (6.93, 79.85))   # nested unpacking
for key, value in d.items():   # .items() yields tuples - this is unpacking too
    ...
```

### Tuples as dict keys

Because they're immutable, tuples can be dict keys — handy for 2-D lookups:

```python
spend = {("2026-01", "Dining"): 12500, ("2026-01", "Transport"): 8300}
spend[("2026-01", "Dining")]
```

## Sets — unique items, fast membership

```python
s = {3, 1, 3, 2}        # {1, 2, 3} - duplicates removed, no order
empty = set()           # NOT {} - that's an empty dict
s.add(5)
s.discard(10)           # remove if present, no error
3 in s                  # True - very fast, even for millions of items
set([1, 1, 2])          # {1, 2}
len(set(items)) != len(items)   # "are there duplicates?"
```

### Set algebra

```python
this_month = {"E01", "E02", "E03", "E05"}
last_month = {"E01", "E02", "E04"}

this_month | last_month   # union: anyone in either
this_month & last_month   # intersection: in both      -> {'E01', 'E02'}
this_month - last_month   # difference: joiners        -> {'E03', 'E05'}
last_month - this_month   # leavers                    -> {'E04'}
this_month ^ last_month   # in exactly one
```

### Why membership speed matters

`x in some_list` checks items one by one. `x in some_set` jumps straight to the answer. For 10 lookups it doesn't matter; for 100,000 lookups against 100,000 items it's the difference between instant and minutes. You'll formalise this as Big-O in Phase 2.

### Sets are unordered

You can't index a set (`s[0]` fails) and printing order isn't guaranteed. When you need a stable output, sort it: `sorted(s)`.

## Which container?

| Need | Use |
|---|---|
| Ordered items you'll change | `list` |
| A fixed group of values (a record, a coordinate, a return pair) | `tuple` |
| Look things up by a key | `dict` |
| Unique items / fast "have I seen this?" / set maths | `set` |
