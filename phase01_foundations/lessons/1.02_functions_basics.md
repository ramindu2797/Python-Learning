# 1.02 — Functions: the minimum

A function packages a piece of logic under a name so you can reuse and test it. From now on, every practice problem is a function.

## Anatomy

```python
def monthly_payment(principal, annual_rate, years):
    """Standard amortised loan payment."""          # docstring: what it does
    r = annual_rate / 12
    n = years * 12
    return principal * r / (1 - (1 + r) ** -n)      # hand the result back

payment = monthly_payment(1_000_000, 0.12, 5)       # call it; store the result
print(round(payment, 2))                            # 22244.45
```

- `def name(parameters):` then an **indented** body (4 spaces).
- **Parameters** are the names in the definition; **arguments** are the values you pass when calling.
- `return` ends the function immediately and hands a value back to the caller.

## `print` vs `return` — the most important distinction in this phase

```python
def add_print(a, b):
    print(a + b)       # shows it on screen... then returns None

def add_return(a, b):
    return a + b       # hands it back to the caller

x = add_print(2, 3)    # displays 5
y = add_return(2, 3)   # displays nothing
print(x, y)            # None 5
```

`print` is for humans looking at the screen. `return` is for other code. The check cells can only test what you **return**. A function with no `return` statement returns `None`.

## Local variables

Variables created inside a function exist only while it runs:

```python
def f():
    temp = 42
    return temp * 2

f()
print(temp)   # NameError: temp only existed inside f
```

This is a feature: functions don't accidentally trample each other's variables.

## Calling functions from functions

Small functions that call each other are how you break big problems down (you'll do this deliberately in Phase 2):

```python
def gross_to_net(gross, tax_rate):
    return gross * (1 - tax_rate)

def annual_net(monthly_gross, tax_rate):
    return gross_to_net(monthly_gross, tax_rate) * 12
```

## Docstrings

The triple-quoted string right after `def` is the docstring. Hover over a function name in VS Code to see it; `help(monthly_payment)` prints it. Write one line saying *what* the function returns. Agent-written code usually has longer ones — read them first; they're the author's intent.

## Testing your own function quickly

```python
print(monthly_payment(1_000_000, 0.12, 5))   # eyeball it
assert round(monthly_payment(1_000_000, 0.12, 5), 2) == 22244.45   # silent if true, error if false
```
