## How to work this phase

- Problems are ordered easy → hard. ★ marks stretch problems — skip them on a first pass if a module is taking too long, and come back later.
- Use the 5-step routine on *every* problem, even easy ones. The point of the easy ones is to make the routine automatic.
- Anything you needed help with → `tracking/redo.md`.

## Done when

You pass Checkpoint 1 in a blank notebook without opening lessons or solutions: four working functions, each planned in comments first.
